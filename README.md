# Buildmart Self-Checkout — Kiosk Prototype

Single-file HTML prototype of a self-service POS kiosk (idle → items → payment → success, staff login/admin, 6 languages, blue/orange/sketch themes). Brandsync-derived tokens.

## Run locally

    npm start        # serves on http://localhost:5180

No build step; edit `index.html` and refresh.

## Workflow

Small, focused branches and PRs against `main`.
